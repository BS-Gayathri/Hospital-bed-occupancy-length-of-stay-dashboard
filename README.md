# Hospital Bed Occupancy and Length of Stay Dashboard

## Project Overview
This project focuses on hospital data analysis and dashboard development using Microsoft Excel and Power Query.

The objective is to clean, transform, analyze, and visualize hospital-related data to support better understanding of hospital operations.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts

## Dataset
The workbook contains four main source tables:

- Patients
- Services - Weekly
- Staff
- Staff Schedule

## Data Cleaning
Power Query was used to clean and transform the source data, review data quality, handle errors and missing values, and prepare the tables for analysis.

## Dashboard Features
- Patient data analysis
- Patient satisfaction analysis
- Hospital service analysis
- Staff information and scheduling
- Excel dashboard visualizations

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- Power Query
- Excel Data Analysis
- Data Visualization
- Dashboard Development

## Project File
The Excel workbook is available in this repository for review.

## Conclusion
This project demonstrates the use of Excel and Power Query to prepare hospital data and present insights through a dashboard.
